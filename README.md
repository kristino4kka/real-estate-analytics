# Анализ рынка недвижимости

Учебный проект по анализу объявлений о продаже недвижимости.

## Цель проекта

Проанализировать рынок недвижимости Санкт-Петербурга и Ленинградской области:
- изучить сроки размещения объявлений;
- определить сезонность публикации и снятия объявлений;
- сравнить среднюю стоимость квадратного метра;
- исследовать площадь и количество комнат.

## Используемые инструменты

- SQL
- Yandex DataLens
- PostgreSQL
